# Lab 10 — Windows, Linux & macOS Support
## Scenario
The corporate environment contains multiple operating systems.

## Tasks
- Windows: services, Event Viewer, networking, user profiles and updates.
- Linux: systemctl, journalctl, permissions, SSH and networking.
- macOS: network settings, user/application troubleshooting and basic system diagnostics.

## Break/Fix
Complete one fault on each OS.

## Deliverables
- Cross-platform troubleshooting matrix
- Commands/reference sheet
- Three incident reports
