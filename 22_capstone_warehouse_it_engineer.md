# Lab 22 — Capstone: Warehouse Site IT Engineer
## Scenario
You are the primary IT Support Engineer I for a simulated warehouse site.

## Environment
- Windows Server domain
- Windows clients
- Linux system
- Cisco network simulation
- DNS/DHCP
- DFS
- Print Services
- Endpoint deployment workflow
- Video conference room
- IT asset inventory
- Network/IT closet documentation

## Mission
Design, deploy, operate and troubleshoot the environment.

## Required incidents
- AD authentication failure
- DNS failure
- DHCP issue
- VLAN/port issue
- Windows workstation failure
- Printer outage
- File-share availability issue
- Software deployment issue
- Video conference issue
- Recurring network problem requiring RCA

## Final deliverables
- Complete network diagram
- IP/VLAN plan
- Server/service inventory
- Asset inventory
- SOP library
- Incident tickets
- RCA
- Change records
- Project plan
- Executive summary
- 10-minute interview-style walkthrough

## Interview readiness
Be able to explain:
- How you troubleshoot from Layer 1 upward.
- How DNS and DHCP interact.
- How AD authentication works at a high level.
- How you protect production availability.
- How you decide whether to fix, escalate or deviate from SOP.
- How you document root cause and prevent recurrence.
