# Lab 07 — Windows Print Services
## Scenario
The warehouse has shared printers used by operations and administration.

## Tasks
- Install Print Server role.
- Add a test printer/driver.
- Publish/share the printer.
- Deploy it to a test client.
- Troubleshoot a print queue.

## Break/Fix
Create a stuck queue, unavailable printer, or driver mismatch.

## Deliverables
- Printer deployment procedure
- Troubleshooting flow
- Recovery checklist
