# Lab 08 — Endpoint Deployment & SCCM/MECM Concepts
## Scenario
The site must deploy applications and updates to many Windows PCs.

## Tasks
- Learn the MECM/SCCM architecture: site server, management point, distribution point, client, collections and deployments.
- In a legal lab environment, practice endpoint inventory and software deployment if you have access to MECM.
- If not, reproduce the workflow using Intune, PDQ-like tooling, or PowerShell scripts.
- Create device collections.
- Deploy a harmless test application/configuration.
- Verify compliance.

## Break/Fix
Troubleshoot a client that is not receiving policy or software.

## Deliverables
- Endpoint lifecycle diagram
- Deployment checklist
- Client troubleshooting tree
- Verification evidence
