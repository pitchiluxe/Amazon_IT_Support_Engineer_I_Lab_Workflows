# Lab 03 — DNS Troubleshooting
## Scenario
Users report that internal applications sometimes cannot be reached by hostname.

## Tasks
- Configure internal DNS.
- Create A, CNAME and reverse records.
- Test with nslookup and Resolve-DnsName.
- Trace DNS resolution from client to server.
- Identify stale/missing/wrong records.

## Break/Fix
Create a bad DNS record and diagnose it from the client side.

## Deliverables
- DNS map
- Commands used
- Fault isolation steps
- Root cause
- Permanent fix
