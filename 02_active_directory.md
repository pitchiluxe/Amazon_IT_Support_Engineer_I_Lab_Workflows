# Lab 02 — Active Directory Domain Controller
## Scenario
Build the identity foundation for a warehouse site.

## Tasks
- Deploy Windows Server.
- Configure a new AD forest/domain in an isolated lab.
- Create OUs for Operations, IT, Management and Devices.
- Create users and security groups.
- Join a Windows client.
- Configure basic Group Policy.
- Test authentication and permissions.

## Break/Fix
Troubleshoot a client that cannot authenticate against the domain.

## Deliverables
- AD architecture
- OU/group design
- GPO list
- Validation screenshots
- Troubleshooting notes
