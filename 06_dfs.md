# Lab 06 — DFS Namespace & File Availability
## Scenario
A site needs a consistent path to operational files even if one file server is unavailable.

## Tasks
- Build two Windows file servers if resources allow.
- Configure a DFS namespace.
- Configure replication where supported by the lab design.
- Test access from a client.
- Simulate one server being unavailable.

## Break/Fix
Troubleshoot namespace access, replication or permissions.

## Deliverables
- DFS design
- Availability test
- Failure test
- Recovery SOP
