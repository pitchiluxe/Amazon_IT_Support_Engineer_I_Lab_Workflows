# Suggested Lab Tools

## Virtualization
- VirtualBox or VMware
- Windows Server VM
- Windows client VM
- Ubuntu VM

## Networking
- Cisco Packet Tracer
- Wireshark
- Windows PowerShell
- ipconfig / nslookup / tracert
- Linux ip / ss / ping / traceroute / dig
- Optional: managed switch/router you own or are authorized to configure

## Documentation
- Markdown
- diagrams.net/draw.io
- Spreadsheet for asset inventory
- Ticket template

## Endpoint management
- MECM/SCCM if available in an authorized lab
- Otherwise reproduce concepts with a suitable endpoint-management or PowerShell lab

## Important
The job description names SCCM. If you cannot build a full MECM lab, learn the architecture, client health, collections, deployments, inventory and troubleshooting workflow, then demonstrate equivalent endpoint-management skills with a legal lab tool.
