# Lab 20 — SOP & Knowledge Base Program
## Scenario
The same five IT issues are repeatedly escalated.

## Tasks
Create production-quality SOPs for:
1. New Windows workstation deployment
2. Password/account issue
3. Network connectivity issue
4. Printer issue
5. Standard software installation

Each SOP should include:
- Purpose
- Scope
- Prerequisites
- Procedure
- Validation
- Common failures
- Escalation
- Rollback
- Owner/review date

## Deliverables
Five SOPs plus one troubleshooting decision tree.
