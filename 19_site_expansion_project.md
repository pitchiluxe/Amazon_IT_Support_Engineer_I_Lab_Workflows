# Lab 19 — Local IT Project: Site Expansion
## Scenario
A warehouse adds a new operations area.

## Tasks
- Gather requirements.
- Build a bill of materials.
- Design VLAN/IP plan.
- Plan endpoints, printers and Wi-Fi dependencies.
- Create implementation timeline.
- Define testing/acceptance criteria.
- Create rollback and communication plans.
- Execute in a lab/simulation.

## Deliverables
- Project charter
- Scope
- Timeline
- Network diagram
- Test plan
- Change record
- Closeout report
