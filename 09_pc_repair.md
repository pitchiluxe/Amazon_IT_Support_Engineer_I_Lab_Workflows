# Lab 09 — PC Repair, Imaging & Deployment
## Scenario
A production workstation fails during an operations shift.

## Tasks
- Diagnose hardware vs OS vs application faults.
- Practice RAM/storage/peripheral troubleshooting on owned equipment.
- Reimage a test PC/VM.
- Install drivers and standard applications.
- Apply baseline configuration.
- Record asset/serial information.

## Break/Fix
Use controlled faults: bad driver, disabled network adapter, corrupted user profile, low disk space, or failed application startup.

## Deliverables
- Repair ticket
- Diagnostic checklist
- Deployment checklist
- Acceptance test
