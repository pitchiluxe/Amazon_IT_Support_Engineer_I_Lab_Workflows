# Lab 01 — Operations IT Baseline & Documentation
## Scenario
You are the site IT engineer taking ownership of a small warehouse IT environment.

## Tasks
- Create an asset inventory for servers, switches, access points, printers and endpoints.
- Document IP ranges, VLANs, DNS/DHCP services and critical dependencies.
- Create a simple network diagram.
- Define production-critical services and acceptable recovery priorities.
- Create a daily IT health checklist.

## Break/Fix
Introduce one documentation error and one unreachable endpoint. Find both without being told which one is wrong.

## Deliverables
- Asset inventory
- Network diagram
- Dependency map
- Daily health checklist
- Escalation matrix
- Test report
