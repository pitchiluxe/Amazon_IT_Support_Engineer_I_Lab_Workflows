# Lab 21 — 12-Hour Operations Shift Simulation
## Scenario
Simulate a full operations IT shift. Do not actually spend 12 continuous hours; run a timed exercise over several sessions if needed.

## Injects
1. Scanner/workstation loses network.
2. Printer queue stops.
3. User cannot authenticate.
4. DNS lookup fails.
5. Conference room issue.
6. New PC needs deployment.
7. Switch port appears down.
8. Critical application becomes slow.
9. Asset return arrives.
10. Manager asks for an urgent report.

## Rules
- Prioritize production impact.
- Document every ticket.
- Communicate status.
- Avoid unsafe/unapproved changes.
- Escalate when outside scope.
- Close each incident with evidence.

## Deliverables
- Shift log
- Priority matrix
- Tickets
- Incident timeline
- End-of-shift summary
