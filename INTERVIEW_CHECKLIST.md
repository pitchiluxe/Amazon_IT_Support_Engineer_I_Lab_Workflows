# Interview / Job Readiness Checklist

## Networking
- [ ] Explain OSI model using a real incident
- [ ] Troubleshoot DNS
- [ ] Troubleshoot DHCP
- [ ] Explain TCP vs UDP
- [ ] Explain IP/subnet/gateway/DNS
- [ ] Explain VLANs and trunks
- [ ] Use basic Cisco show commands
- [ ] Explain Layer-1 cabling troubleshooting

## Windows Server
- [ ] AD users/groups/OUs
- [ ] Group Policy
- [ ] DNS
- [ ] DHCP
- [ ] DFS
- [ ] Print Services
- [ ] Windows services/Event Viewer
- [ ] File/share permissions

## Endpoint support
- [ ] PC hardware diagnostics
- [ ] Imaging/deployment
- [ ] Driver troubleshooting
- [ ] Windows troubleshooting
- [ ] Linux troubleshooting
- [ ] macOS troubleshooting
- [ ] Asset lifecycle

## Operations
- [ ] High-availability mindset
- [ ] Incident prioritization
- [ ] Root-cause analysis
- [ ] Change/rollback planning
- [ ] SOP writing
- [ ] Management communication
- [ ] Project ownership

## Behavioral preparation
Prepare STAR stories for:
1. Difficult technical incident
2. Root cause you discovered
3. Time you improved a process
4. Time you worked under production pressure
5. Time you disagreed with a standard procedure and used a safer/better approach
6. Time you supported a non-technical customer
7. Time you managed a technical project
