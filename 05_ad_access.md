# Lab 05 — AD Users, Groups & Access Control
## Scenario
Warehouse employees need role-based access to shared resources.

## Tasks
- Create role-based security groups.
- Apply least-privilege permissions.
- Create shared folders with NTFS/share permissions.
- Test access as multiple users.
- Document joiner/mover/leaver workflow.

## Break/Fix
Create an access-denied issue and identify whether the problem is group membership, share permissions, NTFS permissions, or authentication.

## Deliverables
- Permission matrix
- Access test matrix
- JML procedure
