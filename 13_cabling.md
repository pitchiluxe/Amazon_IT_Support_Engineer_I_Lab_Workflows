# Lab 13 — Data Cabling & Layer-1 Fault Isolation
## Scenario
A workstation intermittently loses network connectivity.

## Tasks
- Learn structured cabling basics, patch panels, labeling and cable testing.
- Trace a patch from endpoint to switch.
- Inspect link LEDs and switch port state.
- Use an authorized cable tester if available.
- Document port/cable identifiers.

## Safety
Do not work on energized or production cabling without proper authorization and training.

## Deliverables
- Cabling map
- Labeling standard
- Fault isolation report
